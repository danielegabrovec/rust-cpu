# Contribuire

Apri una issue descrivendo sistema operativo, versione del programma, comportamento atteso
e osservato. Non allegare report con attività o informazioni personali senza revisarli.

Per una modifica: branch dedicato, codice Rust formattato, Clippy senza warning, test
di calcolo/protocollo/rendering pertinenti. Mantieni I/O lento fuori dal thread TUI,
assenze esplicite, esportazioni compatibili con schema_version e dipendenze bloccate.

Per aggiungere un sensore documenta fonte, unità, privilegi, hardware provato e comportamento
in assenza del driver. Le stime devono restare riconoscibili e separate dalle misure.
